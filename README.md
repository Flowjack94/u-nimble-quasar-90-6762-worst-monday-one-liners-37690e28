My entry for the make.fun bounty "Worst Monday One-Liners" — one line about the worst Monday ever, aimed at the alarm, the coffee machine, and git blame.

## Entry

> Monday again — my alarm filed ticket #4821, the coffee machine resigned, and git blame says I approved all of it at 3 a.m.

## Run

```sh
python3 main.py
```

`main.py` validates the entry (exactly one line, at most 140 characters, valid UTF-8, no BOM, no control characters, no leading/trailing whitespace) and writes it to `/output/entry.txt`.
